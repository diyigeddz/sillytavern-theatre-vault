# 小剧场仓库 v0.6.3

为 SillyTavern 制作的个人小剧场收藏扩展，数据仅保存在当前浏览器的 IndexedDB 中。

## 目前功能

- 输入框旁的 🎭 快捷入口
- 手机端按当前主题中的卡片实际高度动态计算悬浮窗尺寸，不再依赖固定屏幕百分比
- 空间足够时完整显示 5 篇，短屏自动退为完整 4 篇，不在底部露出半张卡片
- 浏览器顶部栏、底部栏或横竖屏变化时自动重新计算，并按当前可视区域垂直居中
- 手机端长按顶部灰色把手即可拖动悬浮窗，松手后自动记住位置；双击把手或在“⋯”中选择“恢复窗口居中”即可复位
- 单一“＋”新建入口，进入批量新建后可连续增加多个输入框
- 填过的小剧场可收成摘要卡片，当前一篇保持展开，方便连续从手机输入法剪贴板粘贴
- 最后统一“保存全部”；正文为空的输入框自动跳过，并提示保存与跳过数量
- 编辑已有小剧场仍保持单篇模式，不与批量新建混在一起
- 支持一篇小剧场使用多个标签；列表只显示主标签和“+数量”，展开后显示全部标签
- 输入多个标签时可使用中文逗号、英文逗号、顿号或分号分隔
- 名称、标签、全文搜索，以及“全部标签 / 没玩过 / 玩过”筛选
- 旧版单分类会自动作为主标签使用，导入导出同时兼容旧数据
- 新建内容默认是“没玩过”，展开后可手动标记为“玩过”或改回去
- 保留简约灰阶但整体提亮：没玩过的卡片更亮，玩过的卡片稍暗，不再用大面积粉绿区分
- 标记玩过或改回没玩过后保持当前卡片、列表和正文的滚动位置，不再跳回顶部
- 悬浮窗增高后同步增加展开正文的可视高度，同时保持状态、编辑和删除按钮完整露出
- 紧凑列表内直接展开正文，再点一次即可折叠
- 新建保存后默认保持折叠，不会自动撑开正文
- 不同分类自动分配不同颜色，同一分类保持一致
- 展开后可编辑、删除，列表右侧可直接插入
- 每次最多显示 60 篇，可继续分批加载，避免大仓库一次渲染过多内容
- 一键插入酒馆输入框的当前光标位置
- 插入成功后先显示短暂确认，再柔和关闭仓库
- JSON 导入与导出备份
- 备份会保留玩过状态；旧版内容升级后默认归入“没玩过”
- IndexedDB 不可用时自动改用浏览器本地存储
- 页面级点击接管，兼容酒馆重绘或复制输入栏按钮的情况
- 使用浏览器原生顶层弹窗，避免被酒馆主题的缩放和变形规则带跑
- 导入与导出收进右上角“⋯”菜单，避免误触下载

## 安装

### 扩展链接安装（推荐）

在 SillyTavern 中打开“扩展”页面，选择“安装扩展”，粘贴：

`https://github.com/diyigeddz/sillytavern-theatre-vault`

确认安装后刷新页面。看到输入框旁的 🎭 按钮即安装成功。

### 手动安装

将压缩包解压后，把 `theatre-vault` 文件夹放入：

`SillyTavern/public/scripts/extensions/third-party/`

重新启动 SillyTavern 并刷新页面。看到输入框旁的 🎭 按钮即安装成功。

## 备份提醒

小剧场保存在浏览器本地。清理浏览器数据、换浏览器或重装环境前，请先在仓库底部点击“导出备份”。
